## 🚀 Featured projects

### IT Asset Lifecycle & Obsolescence Platform — [`biat-IT`](https://github.com/amenibelhaj/biat-IT)
Web platform built for **BIAT** (bank) to manage the full lifecycle of IT equipment: inventory, lifecycle tracking, **automatic obsolescence classification**, and renewal planning.
`React` · `Node.js / Express` · `PostgreSQL` · deployed on `Render` + `Neon`

### Lawyer–Client Management Platform — [`maitre-belhajsalem-portal`](https://github.com/amenibelhaj/maitre-belhajsalem-portal) · [Live page](https://amenibelhaj.github.io/maitre-belhajsalem-portal/)
Full-stack platform that streamlines how lawyers and clients work together: lawyers manage clients and cases and send reminders and document requests that reach clients **in real time**; clients follow their cases and upload requested files. JWT auth, role-based access, Dockerized.
`React` · `Node.js / Express` · `PostgreSQL` · `Socket.IO` · `Docker`

### Autonomous Trading Agent — [`autonomous-fin-agent`](https://github.com/amenibelhaj/autonomous-fin-agent)
LLM agent that decides BUY / SELL / HOLD from market signals (SMA-20 / SMA-50), using a ReAct-style loop with a portfolio risk-assessment tool. Runs fully local on an open model via Ollama.
`Python` · `LangGraph` · `LangChain` · `Ollama`

### Machine Learning Specialization — [`holbertonschool-machine_learning`](https://github.com/amenibelhaj/holbertonschool-machine_learning)
From-scratch and framework implementations across the ML stack: object detection (YOLOv3), transfer learning, neural style transfer, RNNs & time series, NLP, attention & transformers, GANs & autoencoders, unsupervised learning, and reinforcement learning.
`Python` · `NumPy` · `TensorFlow / Keras`

### Simple Shell — [`holbertonschool-simple_shell`](https://github.com/amenibelhaj/holbertonschool-simple_shell)
